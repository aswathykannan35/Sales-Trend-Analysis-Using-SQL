# Sales Trend Analysis

## Project Overview
This project analyzes monthly revenue and order volumes from an online sales dataset to identify seasonal trends, peak months, and product-level order volume. Analysis was performed using SQL (MySQL) on a cleaned `online_sales` table.

## Key Findings
- **Total Revenue (2022):** 6,105 (currency units)
- **Peak Month:** July 2022 (highest monthly revenue)
- **Highest-Value Orders:** Top orders are dominated by product **P006**
- **Most Frequently Ordered Products:** **P001** and **P003** (highest order counts)
- **Monthly Trend:** Revenue rises from January toward mid-year with several high-performing months (May–October)

## Analysis Summary
- Calculated monthly revenue and monthly unique order counts to observe trends.
- Ranked products by number of orders to identify popular items.
- Identified top high-value orders to highlight products driving revenue.

## Outcome
- Provides a concise view of seasonality and product performance.
- Supports decisions on inventory, promotions, and prioritizing high-revenue products.
- Ready to extend for multi-year comparisons, region-wise analysis, or visual dashboards.
